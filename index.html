1 · Overview

CONTINUUM Signal Chain is a single-file browser performance processor: vintage valve-amp stage, six effect pedals, Loop Station, Destruction, macros, and a 48-channel live performance surface. It runs in real time with the Web Audio API. No install.

INPUT → VINTAGE AMP → FILTER → CHORUS → DELAY → REVERB → PHASER → FLANGER → LOOP STATION → DESTRUCTION → LIVE SURFACE → OUT

Each block can be engaged independently. The Loop Station records the signal after the amp and effect pedals.

Jam / workshop tool. This instrument is for practice, shared jams, and workshops. It has not had rigorous testing. Do not rely on it for a gig or a paid event until that testing is done — bring a backup.

3 · Quick start

  1. Open in Chrome or Edge.
  2. Click ACTIVATE AUDIO. Allow mic if asked.
  3. Choose a source (test tone, mic, or file) → CONNECT SOURCE.
  4. Engage pedals with the footswitches, or use ACTIVATE ALL.
  5. Browse Combined Presets with ‹ › (dials update).
  6. Use each pedal’s dropdown for that unit’s 50 models.

The header pill shows AUDIO LIVE and LATENCY xx ms when the engine is running.

6 · Model banks (approximations)

Amp cabinets use convolution impulse responses (generated cab IRs: closed 4×12, open 2×12, open 1×12, hi-fi). They are cab-style IRs, not samples of a specific commercial cabinet. Other effects remain filter/delay/waveshaper models.

  • Amp path: Preamp drive, tone stack, power-amp stage, supply sag, then cabinet filter and convolution IR.
  • Vintage Amp — physical-style asymmetric valve curve plus a database from AC30, Plexi, JTM45, Bassman, Deluxe, Princeton, Hiwatt, Supro, WEM, Quad II, Dynaco, McIntosh, Marantz, and generics.
  • Filter — Mu-Tron, Q-Tron, DOD, BOSS, Meatball, Moog MF-101, and later boutique/digital filters. Type, Q, range, and LFO follow the model.
  • Chorus / Delay / Reverb / Phaser / Flanger / Loop / Destruction — 50 named entries each, from 1960s classics through current pedals (CE-1, Space Echo, Phase 90, Electric Mistress, RC series, Big Muff, and so on).

7 · Loop Station

Marked Experimental · ~30s buffer. Records the fully effected signal (amp + pedals). Tap buffer is 256 samples and connects only while recording, so it does not add lag during normal play.

ControlFunction
ENGAGEEnables loop playback in the path.
RECRecord, then stop & play; or overdub if a loop exists.

Engage the pedals you want before recording so they are in the loop. Overdub and undo can glitch under load. This is not a hardware-grade looper.

8 · Combined presets

The panel is named Combined Presets (not Presets / Control). It holds 50 full-chain programs. ‹ › loads automatically and updates the pedal dials and engage states. SAVE stores the slot. LOAD reloads it. INIT resets effects.

Examples: Vintage Space, Turbo Drive, Ambient Wash, Tape Echo, AC30 Top Boost, Plexi Stack, Mu-Tron Funk, Space Echo Dream, Dark Ambient.

11 · Latency

Latency is the delay between the moment you play (or the input arrives) and the moment you hear the processed sound. For a musician it is the gap that makes monitoring feel tight or sluggish. This instrument cannot remove delay that lives in the operating system, the audio interface, or a Bluetooth link. It only keeps its own processing as short as the browser allows.

What the header number means

After ACTIVATE AUDIO, the pill LATENCY xx ms is the browser’s own report:

  • Base latency — the Web Audio render quantum (how large a block the engine processes at a time).
  • Output latency — the estimated delay through the output device path.
  • LATENCY xx ms — those two added. It is an estimate, not a measured round-trip from your pickups or mic.

Rough guide: under about 20 ms feels immediate for many players; 20–40 ms is usable; above 40 ms starts to feel late, especially with headphones off and a loud amp in the room. The pill turns warm-coloured when the reported figure is over 40 ms.

What Signal Chain does to keep latency down

  • Lowest buffer request. The audio context is created with latencyHint: 0, which asks the browser for the smallest render block it will allow (tighter than the older interactive hint).
  • No oversampling. Valve and destruction waveshapers run without oversampling. Oversampling reduces aliasing but adds delay, so it is off for live play.
  • Meter is parallel. The level meter taps the master beside the output. It is not inserted in series, so it does not add a block of delay.
  • Looper tap is idle until you record. A live script processor raises latency for the whole page. The Loop Station’s 256-sample tap connects only during REC or overdub, then disconnects. Normal monitoring does not pass through it.
  • Short limiter. The master limiter uses a short attack and no extra lookahead.
Reload the page after an update, then Activate Audio and read LATENCY xx ms. If the number dropped but playing still feels late, the remaining delay is outside the page.

What you control

  • Browser: Chrome or Edge. Safari often sits higher and may not report output latency.
  • Output: Wired headphones or a direct interface. Bluetooth commonly adds 100 ms or more and will dominate the figure.
  • System buffer: In the OS or interface control panel, choose the smallest stable buffer (for example 64 or 128 samples). If you hear clicks, raise it one step.
  • Load: Close other heavy tabs. A second Signal Chain tab is warned against because it can fight for the device.

Status pill (next to latency)

  • AUDIO OFF — click Activate Audio.
  • AUDIO LIVE — engine running.
  • SUSPENDED — the browser paused audio. Click the page (or press a key, or return to the tab) to resume.
  • PERMISSION DENIED — mic or device access was blocked.
  • OUTPUT SELECT FAILED — this browser cannot route to the chosen output; use the system default.
If the reported latency looks low but playing still feels late, the delay is almost certainly outside the page: Bluetooth, a large interface buffer, or monitoring through a DAW. The readout cannot see those.

12 · 48 Channel Live Performance Surface

Formerly described as a 48-channel mixer. It is a performance surface: 48 strips with level, pan, mute, solo, and bus A–D. The processed chain is shared across strips for staging and routing practice. Each lane is independent for level, pan, mute, solo, and bus. It is not 48 separate hardware inputs — one processed source feeds every lane.

RESET MIXER · MUTE ALL · UNMUTE ALL. Header: ACTIVATE ALL, BYPASS, MIDI, SETTINGS (opens this manual).

13 · Tips

  • No sound: Activate Audio → Connect Source → raise Master → unmute a strip → engage pedals or ACTIVATE ALL.
  • Mic silent: Allow permission, pick the correct input, Refresh Devices, Connect again.
  • Dials don’t match a preset: use Combined Presets ‹ › (they sync dials). Pedal dropdowns change only that unit.
  • Dry loop: engage FX before REC.
  • Page flashed old layout: it stays hidden until the pedalboard layout is ready.

14 · Known limits

  • Status: Jam and workshop tool only. Awaiting rigorous testing before any gig or event use.
  • Browsers: Chrome and Edge are the supported targets. Safari may lack output-device selection and some MIDI features.
  • Latency: Context uses latencyHint 0. Header LATENCY ms is browser base + output, not a full round-trip from your instrument. Meter is parallel; looper tap connects only while recording. Wired monitoring and a small system buffer are required; Bluetooth usually is not.
  • Loop Station: Experimental, ~30 seconds, 256-sample tap, post-FX only. Not hardware-grade.
  • Surface: One processed source, many strips.
  • Models: Approximations, not SPICE/IR clones.
  • Saves: Combined presets and the current sound auto-save in this browser. Export/import JSON for a file copy. No cloud account.
  • Bounce: Real-time capture of the master as WebM, 16-bit WAV, or both. Not an offline faster-than-real-time render.
  • Permissions: Mic and MIDI need a user gesture and an allow. Denial is shown on the status pill.
  • Multiple tabs: Warning if another Signal Chain tab is active.
  • UI: Desktop-first; narrow screens reflow the pedal row. Not a native app or plugin.
  • iPad / tablet: Large tap targets, 3-column pedal grid, audio resumes on touch. Chrome or Safari on iPadOS. Add to Home Screen for a fuller view. Prefer a wired or USB interface — Bluetooth adds latency.
  • Shared jam: Loop is up to 3 minutes. Chrome or Edge, one tab, wired headphones. This is a workshop prototype — have a backup if the jam matters.

Offline use · localhost

If you have the HTML file and no internet, the mic will not work from a double-clicked file. Serve the folder and open it in Chrome:

  1. Put the file in a folder, for example Downloads\signal.
  2. In Command Prompt: cd %USERPROFILE%\Downloads\signal
  3. Then: python -m http.server 8080
  4. Open http://localhost:8080/CONTINUUM_SIGNAL_CHAIN_BOSS.html

Leave that window open. localhost is your own computer. An https link (GitHub Pages) is the online equivalent.
